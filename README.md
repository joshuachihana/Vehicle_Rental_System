# Vehicle Rental System

This project is developed for **practice and learning purposes**.

The main goal is to learn and practice:

* Database design and relationships
* Python and Django development
* REST API development with Django REST Framework
* Vehicle rental system architecture
* Managing customers, vehicles, vehicle types, and locations
* Vehicle reservation and rental workflows
* Vehicle pickup and return management
* Vehicle inspection and maintenance management
* Payment management
* Backend system design and business logic

**This is an educational project and is not intended for real-world vehicle rental use.**
